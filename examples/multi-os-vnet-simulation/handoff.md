# Simulation handoff

These files are inert prototype evidence:

- `deterministic-plan.json` declares all 100 results must match.
- `stochastic-plan.json` declares a 94-result quorum before execution.
- `fixture.json` contains 94 identical results and six distinct outliers.

Use the Zoo's built-in `simulate` command. Preserve both reports and every
replica result. Do not relabel this fixture as production infrastructure,
federation evidence, or a proprietary operating-system image.
