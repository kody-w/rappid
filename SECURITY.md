# Security

RAPP Zoo v2 is a local prototype workbench, not a production deployment
platform. Report vulnerabilities privately through GitHub Security Advisories
for `kody-w/rapp-zoo-v2`.

Never include credentials, customer data, private summon bytes, control tokens,
autopilot metadata, or generated reports in an issue.

The supported security boundary is:

- explicit loopback RAPP endpoints;
- private per-estate homes and Electron user data;
- capability-authenticated lifecycle and semantic UI control;
- commit-pinned, hash-verified public data;
- fully saved local receipts before Drill or prototype use;
- synthetic/sanitized prototype data only.
